# LMR File Icons

Icon theme for `.lmr` source files in Antigravity and compatible VS Code editors.

Build this package from this directory with Node.js 22 or later:

```sh
npx --yes @vscode/vsce@4.0.0 package --no-dependencies --allow-missing-repository
```

Install the generated `lmr-file-icons-1.0.0.vsix` from the editor's Extensions view using **Install from VSIX...**. Then select **LMR File Icons** with **Preferences: File Icon Theme**. The theme maps `.lmr` files to the LMR emblem. The main LMR release also attaches this VSIX.
